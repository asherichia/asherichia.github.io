Luminex Data Extractor
Automated data analysis direct from CSV exports

Standalone HTML application for processing of Luminex data CSV files and analysis relative to standards. Provides automated analyte (bead) detection, efficiency calculations on standards, interpolation, hook/low quality standards, and visual plots.

Key Features:
Process direct from Luminex exports
Standard curve validation through 4PL curve, with sample interpolation
Hook effect and low quality standards
Efficiency calculations and interpolation

Alanine Scanning
Protein FASTA sequence mutagenesis tool

Python bioinformatics tool for systematic alanine scanning mutagenesis analysis along a FASTA sequence to generate comprehensive amino acid substitution and sequences. Useful for downstream synthesis/bioinformatics structure-function studies.

Key Features:
FASTA sequence input
Systematic amino acid replacement, single, double and triple mutants
Replaces naturally occurring Ala with Gly

Beta
File parser for plates
Tool for assigning samples to 96/384 well plate layouts

Allows the assigning of imported sample lists (TXT or CSV) to either 96 or 384 well plate layouts. Can be used with plain lists, partially completed well locations, or fully mapped lists to produce standardised output files.

Key Features:
96 or 384 well layouts
Automatic well detection/assignment
Plate visualisation once assigned
HTML in browser use

Beta
CAULDRON
Curve Analysis Using Luminex Data for IC50 and neutRalisatiON

A web-based tool for analyzing neutralization assays using Luminex immunoassay data. Process dilution series to calculate IC50 values through 4-parameter logistic curve fitting.

Key Features:
Upload data → Configure dilutions → Run analysis → Get IC50 results
4-parameter logistic curve fitting for dose-response analysis
Neutralization assay processing with dilution series support
Streamlined workflow for IC50 calculation
